. * Probe (2026-10-10): can an eclass command leave matrices in r() (via an rcl

. * so that `estadd matrix b_std = r(b_std)` works after `dwlsmv, standardized`

. clear all

. program define stdhelper, rclass
  1.     matrix S = (.6, .8)
  2.     matrix colnames S = y1:F y2:F
  3.     return matrix b_std = S
  4. end

. program define fakecmd, eclass
  1.     matrix bb = (1, .5)
  2.     matrix VV = (.01, 0 \ 0, .01)
  3.     matrix colnames bb = y1:F y2:F
  4.     matrix colnames VV = y1:F y2:F
  5.     matrix rownames VV = y1:F y2:F
  6.     ereturn post bb VV
  7.     ereturn local cmd "fakecmd"
  8.     stdhelper
  9. end
